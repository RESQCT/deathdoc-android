# Death Documentation for Android: downloads

Install from **https://deathdoc.resq.work/app**.

This repo holds only the release builds of RESQ's Death Documentation app and `latest.json` (the newest version, its size and SHA-256), which the download page and the app read. The code is private. Every build is signed with the RESQ Death Documentation key, SHA-256 `4F:BF:DC:3B:69:29:15:56:41:60:8F:46:B3:F2:40:7E:B7:78:F4:71:0E:DE:0C:D9:6F:59:A7:5B:7B:14:7E:FA`.
